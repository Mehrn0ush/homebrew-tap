# Homebrew tap for libtea

[libtea](https://github.com/Mehrn0ush/libtea-rs) is an independent command-line
client for the CycloneDX Transparency Exchange API (TEA).

```sh
brew install mehrn0ush/tap/libtea
libtea --version
```

The formula installs the release archives from
[GitHub Releases](https://github.com/Mehrn0ush/libtea-rs/releases): darwin
builds on macOS, and statically linked musl builds on Linux. Homebrew checks
each archive against the SHA-256 in the formula. Those values come from the
release's `SHA256SUMS` after it passes `gh attestation verify`; Homebrew itself
does not check the build-provenance attestation. To check it, follow
[Installing and verifying](https://github.com/Mehrn0ush/libtea-rs/blob/main/docs/installing.md).

`Formula/libtea.rb` is generated by `scripts/make-homebrew-formula.py` in
libtea-rs and updated by pull request after each CLI release
([release checklist](https://github.com/Mehrn0ush/libtea-rs/blob/main/docs/release-checklist.md)).
Do not edit it by hand.

Report problems with libtea in
[libtea-rs issues](https://github.com/Mehrn0ush/libtea-rs/issues).
